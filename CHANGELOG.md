# Changelog

## [Unreleased]

## [0.1.0] — 2026-11-09

### Added
- Bilingual English/Spanish Calcite interface, persistent language selection, and nested non-modal community details.
- Autonomous-community/province filters, compact search, collapsible directory and filter panels, and header map settings.
- Shareable URL state for filters, language, grouping, directory scope, and the rotated map footprint.
- Browser Back/Forward restoration, coalesced search and map checkpoints, and viewport-aware fitting.
- URL/localization regression tests and English documentation.
- GitHub Pages deployment using the existing personal custom domain and a public build-time API-key variable.

### Changed
- Adaptive compositions maximize logos per territory before using dots or counters.
- Directory rows retain stable identities, loaded images, and focus during navigation and language changes.

### Fixed
- Unnecessary municipality-boundary restrictions hiding logos in Pamplona, Zaragoza, and Burgos.
- One/two-item counters, overlapping summary policies, and modal dialogs blocking map interaction.
- Keyboard focus timing in nested details and history camera drift caused by changing legend height.

## Initial prototype

- Reusable ArcGIS group symbol layer, public community snapshots, administrative data preparation, wheel smoothing, and AI/inspiration attribution.
